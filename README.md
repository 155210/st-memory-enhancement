# 记忆增强表格 v2（自用改造版）

基于 [muyoou/st-memory-enhancement](https://github.com/muyoou/st-memory-enhancement) 2.2.19 改造，可以和原版同时安装：

- 在酒馆「安装扩展」里填 `https://github.com/155210/st-memory-enhancement-v2` 安装，文件夹名是 `st-memory-enhancement-v2`，不会覆盖原版。
- 两个都启用时 v2 会暂停并提示；在扩展管理里关掉一个、刷新页面即可切换。
- v2 的设置、模板、聊天表格数据和每层快照都存在自己的键下（带 `_v2`），从不改动原版的数据。
- 第一次运行时会复制一份原版的设置和模板；打开只有原版表格的聊天时，会询问是否导入。导入只复制原版最新的表格，导入前的楼层回退时只读原版快照。
- 设置面板里的「从原版导入」按钮可以随时重新导入当前聊天。

### 大总结交给程序管（设置里可关）

- 事件历史满 20 条时，程序另发一次请求写一条「大」总结，记下楼层范围和涉及角色，然后清空事件；角色表有 `#往事` 列时，顺带追加各角色这段的关键经历。
- 「大」总结攒到 10 + 3 条时，最早 10 条压成一条「卷」，「卷」同理压成「篇」，最近 3 条不压；被压掉的原文一字不改移进「总结归档」表。
- 发送时不整张发归档表，而是按最近几层出场的人从归档里找回最多 5 条相关旧事；大总结里的日期后面标上「几天前」。
- 结果都存在当前楼层，之前楼层不变，回退照常。同一层重 roll 时用上次的结果，不重复请求。
- 老聊天：导入 v2 模板（选「不替换」）→「同步模板到本聊天」→「整理旧大总结」。

### 按需发送

- 角色类表分档发送：最近两层出场的人和时空表「此地角色」里的人发完整一行，最近 30 层出场最多的 10 个主要角色发简要（长格子截短），其余只在名册里列行号和名字；`<user>` 永远完整。行号保持原样，AI 照样能更新。截短的格子被 AI 原样抄回来时不会覆盖原文。
- 条件块：表格规则或消息模板里写 `{{#if 事件历史>=20}}……{{else}}……{{/if}}`，条件按表的行数判断（也可以写 `轮次`），不成立就不发。程序维护的大总结不再发增删改规则。
- 定时提醒：设置里每行写「间隔轮数|提醒内容」，到点时附在表格提示词后面。
- 「本轮注入预览」按钮：看本轮发了哪些表、每张表怎么发的、多少字，以及完整内容。

### 工具

- 「从头回填表格」：新导入的聊天从没有表格的楼层开始，每批几条 AI 回复发一次请求补填表格，开始前确认范围和请求次数；已经有表格的楼层不改，中途再点一次就停，已填的保留。
- 「手动融合总结」：按楼层、正则（比如角色名）、故事日期挑一段正文，让 AI 写一条更细的大总结或卷总结，可以先改再写入，按楼层范围插进大总结表。
- 「撤回大总结」：撤回程序最近一次写的大总结或压缩（含整理旧大总结），最多连撤 3 次。之后又聊了几层也能撤：在最新一层把大总结表和归档表恢复原样，事件放回事件历史，新记的事件保留；同时清掉请求缓存，下次重新请求。
- 额外请求套用预设时，最后（AI 预填充之前）会再放一条用户消息，把这次的任务重说一遍，免得预设的后置指令让模型续写剧情；大总结的回复没有 <summary> 又很长时当成续写剧情，不写进表格。预设面板可以折叠（默认折叠）。表格界面里大总结表和总结归档表默认折叠，点表名展开。
- 额外请求的「停止」立刻生效：中断正在发的请求（自定义 API 直接断开，主 API 调用酒馆的停止），停止前排队的请求一起取消，大总结、压缩不会接着发下一条。
- AI 画地图：要求代码短、不写注释；回复被截断时丢掉最后半个标签补全 SVG，能画多少画多少，并提示调大回复长度。表格里超过 30 字的格子给足宽度，手机上不再挤成一竖条。整理旧大总结中途失败时提示「再点一次接着压」，并显示整理后还剩几条。
- 判断谁在场、找回旧事时，最近几层的正文去掉 <tableEdit>、思考和 HTML 注释再找人名，填表指令里改到的人不再都算在场。
- 设置「找人名时跳过的标签」：填标签名（逗号分隔），正文里这些标签中间的内容在判断在场、找回旧事、触发发送时都不看，比如列了所有人的状态栏。
- 「额外请求套用酒馆预设」：导入酒馆的聊天补全预设 JSON，条目的顺序和开关跟酒馆提示词管理器一样，可以在设置里开关、拖动或点 ↑↓ 调顺序、点名字改内容；📌 条目是 v2 的任务和数据（相当于「聊天记录」的位置），深度注入的条目插进它里面。写法参考 ST-BaiBai-Image。
- 设置页里有「额外请求输出」框：额外请求的进度和流式输出直接显示在这里，点「测试」发一句话试试。
- 「输出面板」：打开底部面板看上一次额外请求的结果或失败原因，点「测试」发一句话看流式输出。
- 「导出诊断」：下载一份 JSON，含版本、设置（不含 API 地址和密钥）、表格概况、最近一次注入和额外请求、最近 30 条报错。
- 「关系图」：角色表、社交表和大总结的「涉及角色」画成关系网，最多 30 人，可拖动缩放，不发给 AI。
- 「角色关系表」（v2 模板第 9 张表）：AI 每轮顺手记录角色和角色之间的关系，关系图用彩色实线画出来。发送时只发和在场、主要角色有关的行，其余只列行号和名字。老聊天要先导入新模板，再点「同步模板到本聊天」。
- 归档表不发给 AI，也不占表格序号，所以新表排在归档表后面也不会让 AI 改错表。
- 设置里可以换表格配色：跟随酒馆主题、暖色纸张、深蓝夜间、青绿、高对比。

### 角色资料卡

- 挂在聊天最底部、最新一楼下面的一根条（设置里也可以放进最后一楼里面），默认收起，条上显示在场的人，点名字展开到她的卡；点卡片头部整张收起。展开后限高、里面自己滚动，左右滑切人不会触发酒馆的切换回复。
- 按名字（含「主名|外号」）合并第一列是名字的表、角色关系表、任务/物品这类按人记的表和悬念簿（涉及角色），每列都显示，短的放格子，`#` 列和长内容折叠；空列不显示但算进「资料缺口」。
- 「最新状态」：每轮生成后读这一楼的 `<Calculated_data>`（标签名可改），按角色存一份到本聊天，只显示表格里没有的项；3 层前的楼被隐藏或删掉标签也不影响。重 roll、滑动按当前显示的那条重存。
- 变化曲线（好感、臣服值、体力、快感、累计高潮次数，每项最近 50 个点，点圆点看那一楼的原因）、生理周期条、规则自检（液体无故减少、胃和膀胱超量、高潮次数变少、数值突变、笼统词）、正文和表格对不上提醒，每条都能生成一句纠正插进输入框。
- 名册页：搜索（含全文）、分组、排序（最近出场、好感、臣服值、名字、最久没出场、token 最多），列出对不上任何角色的名字，可一键设为外号。
- 置顶、头像、分组标签、私人备注、两人对比、剧情书签、小关系图、世界书条目、遮挡私密内容、复制成文字、存成图片、「让她出场」、导出/导入资料卡备份。
- 「精简」按钮：某人的 `#` 长文本太长时让 AI 压缩，先看新旧对比再写回；这是资料卡里唯一会发请求的功能。
- 在场只看最新一条 AI 回复：状态标签里列的人、时空表此地角色、正文里提到的人；设置里可以填资料卡判断在场时跳过的标签。
- 资料卡的数据都只存在本聊天里，不发给 AI。

### 地点和地图

- 地点树：从每条 AI 回复的时间标签（例如『2025年6月15日-星期日–18:15-城南安置房7栋6楼走廊-闷热』）里拆出地点，按「小区/栋/楼/室」这类后缀分层，也认 `异世界>王都>酒馆` 写法。同一个地方只建一次，「6楼走廊」这种省略写法会接回当前所在的楼。一轮有多个标签时取最后一个当当前地点。
- 「地图」按钮：设置里三选一，关闭 / 程序画框图（不花 token）/ AI 画示意图（到新地点时在后台画一次，按地点缓存，最多留 30 张）。
- 找回旧事时也看当前地点的地名；角色表有「住所」列时，住在同一片区域的人发简要。

## 🌟 插件简介

记忆增强插件为您的角色扮演体验注入强大的 **结构化长期记忆**，支持角色设定、关键事件、重要物品等自定义内容。它能有效帮助 AI 更好地理解和记住对话上下文，从而做出 **更连贯、更贴近情境** 的推演。

**插件优势：**

* 😊 **用户友好：**  通过直观的表格轻松查看和编辑记忆，掌控角色记忆。
* 🛠️ **创作者友好：**  便捷导出和分享配置，JSON 文件灵活定制表格结构，满足各种创作需求。

## ✨ 核心功能亮点

* 📅 **结构化记忆储存：** 基于表格的强大记忆系统，未来更将支持节点编辑器，自由定义表格类型和结构。
* ✏️ **灵活内容编辑：** 表格内容完全可编辑，随时浏览和修改，打造专属角色记忆库。
* 🗃️ **自由模板管理：** 可以管理保存多个作用域的模板，以灵活调整表格结构。
* 🤖 **智能提示词生成与注入：** 自动生成精准提示词，深度注入或全局宏，无缝集成世界书或预设，提升 AI 表现。
* 🖼️ **自定义数据推送展示：**  表格内容推送至聊天界面 DOM，自定义样式，重要信息醒目可见。
* 📦 **便捷配置导出与分享：**  提供丰富的自定义选项（提示词、注入方式等），预设轻松导出和分享表格结构和设置。
* 🚀 **分步操作：**  未来结合主副 API，实现任务智能分配（生成、整理、重建等），支持自定义触发时机，高效管理记忆。
